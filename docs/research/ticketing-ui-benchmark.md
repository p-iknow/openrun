# 예매 사이트 화면 벤치마킹

조사일은 2026-11-08이다. 1.2 디자인 기반에서 시각적 방향과 `store-ui` 컴포넌트 범위를 정하기 위해, 1.3 조회 범위(공연 목록, 제목 검색, 장르·판매 상태 필터, 정렬, 페이지, 공연 상세)에 해당하는 화면을 봤다.

## 표기와 방법

- **대상:** NOL 티켓(구 인터파크 티켓), YES24 티켓, 멜론티켓, 티켓링크, Ticketmaster(미국)
- **방법:** 로그인하지 않은 Chrome에서 각 사이트를 직접 열어 데스크톱(1440px)과 모바일(390px) 폭으로 확인했다. 글꼴과 색은 브라우저에서 계산된 스타일 값을 읽었다.
- **표기:** **관찰**은 화면에서 직접 본 것이고, **추론**은 관찰에서 끌어낸 판단이다. 티켓링크 상세는 예매 안내 모달이 화면을 가려 일부만 봤다.

## 결론 요약

- **목록은 주로 세로 포스터 카드 그리드다(관찰).** NOL, 멜론티켓, 티켓링크는 데스크톱에서 4~5열 그리드를 쓰고, 카드는 포스터, 제목(2줄 말줄임), 공연장, 기간, 작은 태그 순서다. 포스터 비율은 대략 3:4이다. YES24 검색은 표 형태의 가로 행이고, Ticketmaster는 가로형(16:9) 카드와 회차 행을 쓴다.
- **번호 페이지를 쓰는 곳은 없다(관찰).** NOL, 멜론티켓, 티켓링크는 무한 스크롤이고, YES24 검색과 Ticketmaster는 "더보기" 버튼이다. ROADMAP 1.3의 오프셋 페이지와 다르다.
- **가장 풍부한 필터는 NOL의 여러 개 고르는 칩이다(관찰).** NOL은 데스크톱에서 왼쪽 필터 패널, 모바일에서 가로 스크롤 칩 줄과 바텀 시트를 쓰고, 판매 상태와 장르를 여러 개 고를 수 있다. 다른 곳은 더 단순하다. YES24는 하위 장르 탭과 "판매마감 제외" 체크박스, 멜론티켓은 하위 장르 탭, 티켓링크는 지역 칩을 쓴다.
- **정렬은 2~4개 선택지다(관찰).** NOL은 드롭다운(추천순, 예매 많은 순, 종료 임박 순, 최근 등록 순), 멜론티켓은 텍스트 탭(인기순, 공연임박순, 최신순), YES24는 텍스트 탭(정확도, 신상품순, 상품명순), Ticketmaster는 Relevance와 Date다.
- **상세는 포스터와 정보 옆이나 아래에 예매 영역을 둔다(관찰).** NOL은 2단 구성으로, 데스크톱은 왼쪽에 포스터와 정보, 오른쪽에 달력, 회차, 예매 버튼이 고정되어 따라오고, 모바일은 화면 아래에 예매 버튼이 고정된다. 멜론티켓은 정보 박스 바로 아래에 달력과 시간 선택을 둔다. 정보 영역은 탭 또는 앵커 탭(공지사항, 캐스팅, 가격, 취소 및 환불규정, 장소, 리뷰)으로 나뉜다.
- **브랜드 색은 한 가지를 강하게 쓴다(관찰).** NOL 파랑, YES24 주황, 멜론 초록, 티켓링크 빨강이다. 화면 대부분은 흰 바탕에 검은 글자이고, 브랜드 색은 주요 버튼, 선택된 칩, 선택된 탭에만 쓴다.

## 사이트별 관찰

### NOL 티켓

- **글꼴과 색:** Pretendard. 본문 글자색 `rgb(27, 28, 31)`, 주요 색 `rgb(65, 84, 255)`. 예매 버튼은 높이 52px, 모서리 16px다.
- **장르 화면:** 큐레이션 섹션(오픈 예정, 할인 중, 랭킹, 지역 추천, 둘러보기)을 세로로 쌓는다. 섹션 안은 가로 캐러셀이고, 상단에 섹션으로 이동하는 앵커 탭이 붙는다.
- **검색 결과:** 데스크톱은 왼쪽 필터 패널(판매 상태, 장르, 지역 칩과 초기화) + 오른쪽 결과 4열 그리드다. 결과 위에 "371개 검색결과"와 정렬 드롭다운이 있고, 선택된 필터가 지울 수 있는 칩으로 다시 보인다. 무한 스크롤이다.
- **카드:** 포스터, 제목, "서울 · 공연장", 기간, 별점(후기 수), "좌석우위"·"단독판매" 같은 작은 태그.
- **모바일 검색:** 그리드가 가로형 목록(왼쪽 포스터, 오른쪽 장르, 제목, 공연장, 기간, 별점)으로 바뀐다. 상단에 장르, 지역 드롭다운 칩과 필터, 정렬 버튼이 가로 스크롤로 놓이고, 필터는 바텀 시트에서 고른 뒤 "10,000개 상품 보기"로 적용한다.
- **상세:** 왼쪽에 포스터를 흐린 배경 위에 올린 큰 영역, 제목, 리뷰 수, 앵커 탭, 장소·기간·시간·연령 정의 목록이 있다. 오른쪽 예매 패널은 달력, 선택한 회차(시간, 등급별 잔여석, 출연진), 예매하기 버튼으로 구성된다. 모바일은 하단 고정 버튼이다.

### YES24 티켓

- **글꼴과 색:** NanumBarunGothic. 주요 색은 주황(`rgb(255, 125, 30)`).
- **장르 화면:** 큰 배너 캐러셀, WHAT'S HOT, 랭킹, PICKS를 쌓은 큐레이션 화면이다. 필터가 있는 전체 목록은 없다.
- **검색 결과:** 탭(통합검색, 공연, 공지사항 등)과 건수, 하위 장르 탭(뮤지컬(9,626) 등), 정렬 텍스트 탭, "판매마감 제외" 체크박스가 있다. 결과는 표 형태의 가로 행(포스터, 판매 상태 배지, 제목, 기간, 공연장)이고, "더보기"로 더 불러온다.
- **판매 상태:** "판매중"을 주황 배경 배지로, "단독판매"를 빨간 테두리 배지로 표시한다.
- **상세:** 상단에 장르 경로, 태그, 큰 제목, 기간과 공연장이 있고, 아래에 포스터와 정보 표(등급, 관람시간, 출연, 혜택)가 나란히 있다. 판매가 끝난 공연은 예매 영역 자리에 "판매가 종료된 상품입니다."를 회색으로 보여 준다. 그 아래는 탭(상세정보, 관람후기, 예매/취소 안내)이다.

### 멜론티켓

- **글꼴과 색:** Apple SD Gothic Neo(시스템 글꼴). 주요 색은 초록(`rgb(65, 210, 107)`).
- **장르 목록:** 추천 4개 카드 다음에 하위 장르 탭(전체, 뮤지컬, 연극), 목록·그리드 보기 전환, 정렬 텍스트 탭이 있고, 4열 그리드다. 카드 아래 태그는 "좌석우위"(채움), "청년패스"(채움), "판매중"(초록 테두리)이다. 번호 페이지는 없다.
- **상세:** 상단 박스에 포스터, 태그, 제목, 정보 2열 표가 있고, 바로 아래에 날짜 선택(달력)과 시간 선택이 2단으로 붙은 예매 영역과 예매하기 버튼이 있다. 그 아래는 탭(상세정보, 기대평, Q&A, 공연장정보, 예매안내)이다.

### 티켓링크

- **글꼴과 색:** Noto Sans. 주요 색은 빨강.
- **장르 화면:** 큰 배너, 랭킹(일간·주간·월간·연간), 추천공연, 지역 순서다. 지역 섹션이 전체 목록 역할을 하고, 지역 칩(전체, 서울, 경기/인천…)으로 거르며 무한 스크롤한다.
- **카드:** 지역, 제목, 공연장, 기간, 태그(단독판매는 빨강 채움, 청년패스는 테두리). 포스터가 로드되기 전에는 회색 자리 표시자를 보여 준다.
- **상세:** 포스터 옆에 장소, 관람시간, 관람등급과 등급별 가격(VIP석, R석, S석), 할인 목록을 표로 보여 준다. 처음 열 때 예매 안내 모달이 뜬다.

### Ticketmaster

- **장르 화면(Broadway):** 어두운 바탕, 가로형(16:9) 이미지 카드와 카드마다 "Find Tickets" 버튼이다. 상단에 섹션 앵커 탭이 있다.
- **검색 결과:** 위치, 날짜, 검색어를 한 줄에 둔 검색 막대가 있다. 결과는 공연이 아니라 **회차 행**(날짜 블록, 요일과 시간, 제목, 도시와 공연장, Find Tickets 버튼)이고, 정렬은 Relevance와 Date 두 가지, "More Events"로 더 불러온다.

## 오픈런에 주는 시사점(추론)

- **정보 구조는 업계 공통 패턴을 따른다.** 목록은 3:4 포스터 카드 그리드, 모바일은 가로형 행 목록, 필터는 여러 개 고르는 칩, 상세는 2단과 따라오는 예매 패널, 모바일은 하단 고정 버튼으로 둔다. 이 부분은 방향마다 바꾸지 않는다.
- **시각 표현도 업계 관습을 따른다.** 국내 네 곳은 모두 흰 바탕, 산세리프, 브랜드 색 하나를 쓴다. 이 관습을 따르면 실제 서비스처럼 보이고, 특정 사이트와 닮아 보여도 괜찮다. 시각적 방향끼리는 색과 글꼴, 모서리, 밀도로 구별한다.
- **`store-ui` 컴포넌트 후보가 늘어난다.** 모바일 필터 바텀 시트(Base UI Drawer 또는 Dialog), 선택된 필터를 다시 보여 주는 지울 수 있는 칩, 포스터 자리 표시자(Skeleton)가 조회 화면에 필요하다.
- **페이지 방식은 결정이 필요하다.** 업계는 번호 페이지를 쓰지 않지만, ROADMAP 1.3은 오프셋 페이지를 명시하고 9단계는 오프셋 페이지 성능을 측정한다. "더보기" 버튼도 오프셋으로 구현할 수 있다.
- **판매 상태 배지는 상태마다 다른 강도로 표시한다.** 판매 중은 강조, 판매 예정은 중립으로 둔다. 매진과 회차 취소는 공연 판매 상태가 아니다([공연 판매 상태](show-sales-status.md)). 매진 임박은 판매 상태가 아니고 회차의 정보라서 목록 카드에 두지 않는다.
