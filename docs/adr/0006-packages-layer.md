# 앱이 함께 쓰는 코드는 `packages/`에 두고, 앱끼리는 서로 import하지 않는다

[0002](0002-monorepo.md)의 `apps/*` 옆에 `packages/*`를 두고, 여러 앱이 쓰는 코드는 이곳에만 둔다. 앱은 패키지를 import할 수 있지만 다른 앱은 import하지 못한다. 첫 패키지인 `packages/api-client`는 `apps/api`가 만들어 커밋한 `openapi.json`에서 타입을 생성하고, 스토어와 어드민은 이 패키지로만 API를 호출한다. 프론트엔드가 NestJS의 DTO 클래스를 직접 import하면 타입은 공짜로 얻지만 화면 번들이 `@nestjs/swagger`와 서버 코드에 묶이고, 리뷰에서 API 계약이 바뀐 것을 코드 diff 속에서 찾아야 한다. 앱마다 클라이언트를 생성하면 같은 생성 설정이 앱 수만큼 생긴다. 그래서 계약 파일 하나를 경계로 삼고, 생성 단계가 하나 늘어나는 비용과 명세를 갱신하지 않으면 커밋이 막히는 비용은 감수한다. 패키지는 `dist`로 빌드해 내보내므로, Turborepo에서 앱의 빌드와 타입 검사는 패키지 빌드(`^build`) 뒤에 실행된다.
