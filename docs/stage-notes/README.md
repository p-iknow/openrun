# 단계별 기록

단계마다 `NN-단계이름.md` 파일을 하나씩 만들고 아래 내용을 짧게 적는다.

- **선택 이유:** 무엇을 왜 골랐는가
- **쓰지 않은 기술:** 무엇을 왜 쓰지 않았는가
- **측정 결과:** 수치, 측정 환경, 데이터 규모, 부하 생성 위치
- **회고:** 예상과 달랐던 점, 아직 설명하기 어려운 점
- **면접 대비:** 티켓의 이해 확인 질문 중 면접에 쓸 만한 것. 항목은 질문을 제목으로 두고 아래 순서로 적는다.
  - **질문 의도:** 면접관이 이 질문으로 무엇을 보려는가
  - **검증하려는 것:** 답에 들어가야 할 개념과 사실
  - 답: 이 프로젝트의 코드와 결정에 기대어 설명하고, 직접 확인한 근거(실험, 테스트, 실행 결과)를 함께 적는다

괄호 안 번호(`#22`)는 PR이 아니라 이슈 번호를 쓴다.
